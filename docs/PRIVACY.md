# 隐私说明

最后更新：2026-09-02

## 数据处理

ChatGPT LaTeX Copy 仅在 `https://chatgpt.com/*` 页面运行。为了将页面公式恢复为 LaTeX，它会观察页面自身的相关 Network 响应，并把当前页面的 assistant message ID 与 raw message content 临时保存在浏览器内存中。

## 不收集、不传输

扩展不收集、不出售、不共享、不上传以下信息：

- ChatGPT 对话内容；
- 身份信息、账号信息、Cookie、认证令牌或密码；
- 浏览历史、设备标识符或使用分析数据。

扩展不包含远程代码、广告、分析 SDK 或任何自有服务器。

## 本地复制

用户点击页面内的复制按钮时，选中的普通文本和 LaTeX 会写入系统剪贴板。这是扩展的核心功能；写入结果由用户自行粘贴到目标应用。

## 风险提示

浏览器扩展有能力接触匹配网页的内容。请只从可信来源安装本项目，并在处理敏感 ChatGPT 对话前自行审查源码。

## 联系方式

发布者应在公开 GitHub 仓库的 README 或仓库主页中补充有效联系渠道。
